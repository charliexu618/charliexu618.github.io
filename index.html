Personal desktop publishing tool

Nightly Curiosity Upload Console

A local workflow for the owner of Patitas en Inglés and Nightly Curiosity to manage their YouTube channels.

What the application does

The application uses the open-source yutu MCP server and the YouTube Data API to verify the selected channel, upload owner-approved videos, update video metadata, set thumbnails and manage playlists. The owner chooses the video, channel and publication settings.

Why Google access is requested

Google OAuth authorizes this desktop tool to access the owner's selected YouTube channel. Channel and video information is used to confirm account identity, track upload processing and verify publication results. The application runs in the owner's local production environment.

Use and support

This tool is for the owner's personal channel workflow. It has no public account registration or online upload form. Contact the operator through charliexu618 on GitHub or the support address shown on the Google consent screen.
