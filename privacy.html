Privacy policy

Effective date: 6 October 2026. This policy describes the owner's personal desktop channel-publishing workflow.

Information accessed and its purpose

The application accesses authorized YouTube channel identifiers and channel information, video identifiers, metadata, publication settings and processing results. The owner provides media files, thumbnails and metadata for publication. These data support the channel-management functions described on the application homepage.

Storage and processing

The upstream yutu application manages OAuth credentials and cached tokens in the owner's local account directories. The local workflow stores video files, publication manifests, API receipts and verification results. Authorized automation and assistant tools may process publication metadata and results to carry out the owner's requests. OAuth credentials are not included in this public information site.

Sharing and use

Approved media and metadata are sent to Google/YouTube for the selected publishing operation. Publication visibility is controlled by the owner's approved settings. Google user data is used for this channel-management workflow, not sold, used for advertising or used to train generalized AI models. Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Retention, deletion and revocation

The owner retains local files and receipts as needed to operate the channels and avoid duplicate submissions. The owner can delete local records and revoke access through Google Account permissions. Revoking access stops future authorized API access; it does not automatically remove local files or videos already uploaded to YouTube. Uploaded content can be managed separately in YouTube.

This website and contact

This information site contains no application login, upload form, analytics script or application-set cookies. Its hosting provider may process ordinary request logs. Questions or deletion requests can be directed to the operator through charliexu618 on GitHub or the support address on the Google consent screen.
